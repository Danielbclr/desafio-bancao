# Desafio de Programação
Este projeto é uma API Rest para gerenciar transações bancárias e gerar estatísticas e é idealizado apenas como experiência de aprendizado. É desenvolvido em Java com Spring Boot e é baseado no desafio: [rafaellins-itau/desafio-itau-vaga-99-junior](https://github.com/rafaellins-itau/desafio-itau-vaga-99-junior).

## Roadmap de features

   - [ ] Endpoint ```DELETE /transacao```

- [ ] Unit tests
